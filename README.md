# App support

GitHub Pages serves static files from `main`. The root redirects to Support.

- `/privacy/` and `/support/` serve the English documents.
- `/es/privacy/` and `/es/support/` serve the Spanish translations.
- Add each app to both languages using the same app slug as the section ID. For example, use `#kttl` on each localized route.
- Keep published URLs and anchors working when updating the documents.
