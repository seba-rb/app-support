kttl

kttl es una app independiente para el hervidor Fellow Stagg EKG Pro, modelo EP20AAUK.

  1. Abre kttl, toca Buscar hervidor y permite Bluetooth cuando iOS lo pida.
  2. Selecciona el hervidor y sigue la configuración de Wi‑Fi. Permite Red local cuando aparezca el aviso.
  3. Si la conexión no se verifica, comprueba que el iPhone y el hervidor pueden comunicarse en la misma red local y sigue la opción de recuperación que muestre kttl.

Si el problema continúa, incluye el modelo y firmware del hervidor si están disponibles.

kttl

kttl is an independent app for the Fellow Stagg EKG Pro kettle, model EP20AAUK.

  1. Open kttl, tap Find kettle, and allow Bluetooth when prompted.
  2. Select the kettle and follow the Wi‑Fi setup. Allow Local Network access when prompted.
  3. If the connection cannot be verified, check that your iPhone and kettle can reach each other on the local network and follow the recovery action in kttl.

If the issue continues, include the kettle model and firmware if available.
